# ppu-indra-ocr scope: decisions

Date: 2026-10-14

Context: Datalab Indra OCR (code Apache-2.0, weights modified OpenRAIL-M).
A license clearance email went to Datalab on 2026-10-14. Attachment A 2(c)
(competitor ban) is the open question. Nothing is released until they reply.

| #   | Question                     | Decision                                                                                                                                                                                                                                                                                              | Why                                                                                                                      |
| --- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Q1  | Repo location and visibility | Local `~/Documents/project/ppu-indra-ocr`, private GitHub repo `PT-Perkasa-Pilar-Utama/ppu-indra-ocr`. No npm, JSR or HF publish until Datalab replies.                                                                                                                                               | CI and backup without distribution.                                                                                      |
| Q2  | Copy method                  | Fresh history. Working tree of ppu-paddle-ocr `8c028eb` (v6.6.1), one scaffold commit.                                                                                                                                                                                                                | Paddle history and tags do not belong to this project.                                                                   |
| Q3  | Package license              | Apache-2.0, NOTICE credits datalab-to/indra (Apache-2.0) and ppu-paddle-ocr (MIT). Copied scaffold headers flipped to Apache-2.0 too (user confirmed; PT PPU owns that code). Weights stay under Datalab's OpenRAIL-M.                                                                                | Pipeline is a translation of Apache code.                                                                                |
| Q4  | What carries over            | Everything relevant: core, CLI, web, mobile, serve, playground, binaries, tooling, workflows. Drop paddle-only files (devto article, migration docs, paddle models, old CHANGELOG history).                                                                                                           | Same DX as ppu-paddle-ocr. Pieces that may compete are dropped only if Datalab's reply requires it.                      |
| Q4c | Port order                   | Port everything now. Release after the reply.                                                                                                                                                                                                                                                         | User decision.                                                                                                           |
| Q5  | Runtimes                     | Node, web and mobile in v1.                                                                                                                                                                                                                                                                           | Follows Q4c.                                                                                                             |
| Q6  | Image engine                 | Both engines. `opencv` (ppu-ocv) default for parity, `canvas-native` kept. Connected components in pure TS on tensors, shared. Mobile keeps Skia.                                                                                                                                                     | Indra needs only resize, warpAffine and connected components.                                                            |
| Q7  | Pipeline scope               | All stages: orient, skew, det, script, rec, rec_cjk, order with layout heads, markdown. Math opt-in, lazy download. PDF `mode: auto/ocr/text` on a separate entry `ppu-indra-ocr/pdf`.                                                                                                                | Auto mode with the text layer is the headline score (62.1 vs 57.5 OCR-only).                                             |
| Q7a | Stage access                 | Every stage is a public API. The full pipeline composes the same calls.                                                                                                                                                                                                                               | Users can run the whole pipeline or chain stages.                                                                        |
| Q7b | PDF engine                   | pdfium wasm (`@embedpdf/pdfium`, MIT) as an optional peer dep. Fallback `@hyzyla/pdfium`, then pdf.js with re-tuned checks, only after asking. Not ppu-pdf.                                                                                                                                           | ppu-pdf hard-depends on AGPL `mupdf`. pdfium matches pypdfium2 for text-layer parity.                                    |
| Q8  | Model source                 | Model catalogue primary: upstream HF `datalab-to/indra-ocr` pinned to commit `d7c839c892bfe4b8993373db64c62f154d05d70b` (tag v3.1).                                                                                                                                                                   | No silent upstream drift. meta.json holds the vocab.                                                                     |
| Q8b | Mirrors                      | `models/` in this repo via git LFS: v3.1 files unmodified, `models/LICENSE`, `models/README.md` (credit, link, commit, Attachment A). Catalogue order: upstream HF, GitHub raw mirror, `snowfluke/indra-ocr` HF slot reserved for after the reply. sha256 test against upstream.                      | OpenRAIL 4(b) and 7 need the license and credit next to the files. The checksum proves the files are unmodified.         |
| Q9  | Parity tests                 | Committed stage-level goldens from `indra-ocr==0.3.1` via `uvx`, generated by hand with `scripts/golden/gen.py`. About 8 fixtures we own or generate (listed before generation). opencv: exact text and markdown, box IoU >= 0.98, same order and labels. canvas-native and mobile: token-F1 >= 0.98. | Exact parity on the default engine proves the tuned constants survived the port. Stage goldens show which stage drifted. |
| Q10 | API shape                    | `IndraOcrService` with `convert()` (full pipeline, returns `Page`), stage methods `orient`, `straighten`, `detect`, `recognize`, `order`, `readMath`; pure exports `toMarkdown`, `orderXYCut`, `joinLines`; one-shots `ocr()`, `detect()`; `convertPdf()` from `/pdf`.                                | `recognize` means only the recognition stage. `convert`/`Page` match upstream.                                           |
| Q11 | Release and CI while private | Version 0.1.0, fresh CHANGELOG. Name `ppu-indra-ocr` (npm, JSR, CLI). `codeql.yml` and `scorecard.yml` skip when the repo is private. No publish secrets until go. Other workflows unchanged.                                                                                                         | Free-plan private repos lack code scanning. Missing secrets block release by themselves.                                 |
