# Indra OCR 1.2 port: decisions

Date: 2026-11-25

Context: Datalab released `indra-ocr` 1.2.0 on PyPI on 2026-11-24, with new
weights at Hugging Face tag `v1.2.0` (commit
`a04fa100e778192aa54d040a983983c6d3ee4ce5`). The weights license lowers the
revenue and funding limits in Attachment A 2(a) and 2(b) from USD 20,000,000
to USD 5,000,000. Clause 2(c) (competitors) is unchanged. Tag `v1.1.0` keeps
the USD 20,000,000 text.

| #   | Question          | Decision                                                                                                                                                                                                                           | Why                                                                                                                              |
| --- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Q1  | Weights mirror    | No mirror of v1.2. The files sit in a local, git-ignored `models/v1.2/` for `scripts/golden`; tests and CI download them from Datalab. No Hugging Face upload by the agent. LICENSE-STATUS.md records both thresholds, per preset. | User decision. The repository's git LFS budget was exhausted on the first push, and mirroring is Distribution under the license. |
| Q2  | Presets           | `v1.2` (default), `v1.1`, `v3.1`. One pipeline runs all three: upstream gates each new stage on the model file being present, and the line thumbnails on the `thumbs` input of `order.onnx`.                                       | User decision, same as the 1.1 port. Goldens are regenerated for all three.                                                      |
| Q3  | Math default      | On for Node and Bun, off for web and mobile.                                                                                                                                                                                       | User decision. Matches upstream on servers; keeps the browser download small.                                                    |
| Q4  | Scope             | The default code path of 1.2.0 only.                                                                                                                                                                                               | User decision. The opt-in features are listed below as follow-up work.                                                           |
| Q5  | Native kernels    | Not ported (`native.py`, the `indra-ocr-native` C++ package).                                                                                                                                                                      | Upstream says they give the same results as the Python code they replace.                                                        |
| Q6  | ORT session setup | Not ported (`ort_session.py`).                                                                                                                                                                                                     | It sets CUDA arena limits. The TS package runs on CPU, wasm and WebGPU providers.                                                |

`difflib.SequenceMatcher` (used by the math accept head, the prose splice and
the symbol-digit check) is ported in `src/indra/sequence-matcher.ts` with

`src/indra/py-unicode.ts` (`html.escape` and `html.unescape` in
`src/indra/py-text.ts`).

## Changed during the port

| Topic                                                  | Upstream 1.2.0                                                                                    | Built                                                                                             | Why                                                                                                       |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Text-layer check on v3.1                               | `layer_gaps` asks every recognizer for top-k outputs; the v3.1 ones have none, and the page fails | A recognizer without top-k outputs or logits gives no gap: its lines drop out, as math lines do   | Keeps the legacy preset reading PDFs. `scripts/golden/gen.py` records the same rule for the v3.1 goldens. |
| Accepted math readings                                 | A dict on the `MathReader`, cleared per page                                                      | A typed `math` record on the replaced `RecLine` and its part                                      | No shared mutable state between pages read at the same time.                                              |
| Spliced formula tokens                                 | `Formula` and `Pad`, subclasses of `str`                                                          | An optional fourth token field, `Splice`; text-layer tokens are told apart by their content index | JavaScript strings cannot carry a type; the decoders checked tuple length before.                         |
| Model loading                                          | Every session at load                                                                             | `rec_hw.onnx` on the first handwritten line, the table models on the first table                  | The same lazy loading as the script recognizers; a page without tables never downloads them.              |
| Text layer after render                                | Reads the layer from a second document opened after the check render (pdfium glyph boxes)         | Reads the layer from the same document                                                            | The PDF goldens match without it. Port it if a fixture shows boxes from font metrics.                     |
| Tie order                                              | `np.argsort` (not stable) in `read_turn` and `alignment`, `argpartition` in `_top_k`              | Stable sorts, ties to the lower index                                                             | Ties need equal float widths or logits; no golden has one.                                                |
| LM beam search                                         | Rewritten for speed, same results                                                                 | Not rewritten                                                                                     | The beam-search goldens match the existing port.                                                          |
| `hw_conf_gate`, script `hw` class, `INDRA_*` variables | Supported                                                                                         | Not ported                                                                                        | No preset's meta.json or script.onnx uses them; the variables are debugging switches.                     |
